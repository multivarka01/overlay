# studio.html — журнал изменений

Совместимость: CSP не менялась (script-src/connect-src прежние), названия RPC и таблиц Supabase те же (`get_overlay_scene`, `rotate_overlay_key`, таблица `scenes`, bucket `images`), формат сцены прежний (массив элементов + `type:'meta'` v2), ключи localStorage прежние. Старые сцены и ссылки OBS продолжают работать.

## Исправлено

- **Квота localStorage.** Ключи `hs`, `hs-scenes`, `hs-ws`, `hs-wk` пишутся по отдельности; ошибка квоты не теряет состояние в памяти, пользователь получает одно сообщение.
- **Размер Realtime-сообщения.** Если `JSON.stringify(items)` больше ~150 КБ, вместо `scene` отправляется крошечный `refresh` (после успешного сохранения в базу). Страница оверлея по `refresh` вызывает `fetchOverlay()`. Для BroadcastChannel (тот же браузер) по-прежнему уходит полная сцена.
- **Оверлей (OBS).** Переподключение при `CLOSED / CHANNEL_ERROR / TIMED_OUT` с экспоненциальной паузой (1 с → 30 с), резервный опрос раз в 20 с, повтор при событии `online`, устаревшие каналы не плодятся. Прозрачный фон сохранён. Цикл `requestAnimationFrame` стал дешевле: нет `querySelectorAll` на кадр, `transform` пишется только при изменении, таймер обновляется ~5 раз в секунду. Опрос не откатывает сцену, пока идёт живое перетаскивание.
- **Гонки сохранения.** Параллельные сохранения одной сцены выстроены в очередь; флаг «не сохранено» снимается, только если после отправки не было новых правок; опрос `pollSync` отбрасывает ответ, если за время запроса была правка, идёт перетаскивание или сохранение, либо есть несохранённые изменения. Если строка сцены исчезла в базе, она создаётся заново.
- **Повторы и статус.** Неудачное сохранение повторяется с паузой 1→30 с (и сразу при `online`). Статус в `#st`: «сохранено», «сохраняю…», «нет связи, повторю», «локально» (и «демо»).
- **Закрытие вкладки.** `beforeunload` предупреждает только при несохранённых изменениях; `pagehide` и переход вкладки в фон сбрасывают очередь сохранения.
- **Удаление стримера в меню.** Теперь как в app.html: подтверждение (danger) → `delete().eq('name',n).select()` строки `scenes`, очистка `ROWS`/`WSMAP`/ключей синхронизации; при ошибке — уведомление, запись остаётся. Свой канал нельзя удалить, он только скрывается через `hs-hidden` (список учитывается в меню и в «Другому стримеру»; «Добавить канал» возвращает его). Если удалён текущий стример, редактор переключается на другого, не пересоздавая строку.
- **Перенос элемента другому стримеру.** Если не удалось прочитать сцены получателя, элемент не копируется (раньше могла быть перезаписана чужая сцена). Лимит 200 элементов проверяется явно.
- **`fmt`** была объявлена дважды (таймер и числа панели) — переименована; убран мёртвый код и CSS (`.bg`, `.bg-blob`, `.brand`, `.lm`, `#chSel`, `#back`, неиспользуемые keyframes, несколько «скинов»).
- **Ошибка в перетаскивании:** таймер отправки позиции мог обратиться к уже сброшенному `drag`.
- **Ввод.** Только https-адреса (без логина и пароля, ≤2000 символов), ник — `^[a-z0-9_]{1,25}$`, числа в панели ограничены (X/Y ±20000, ширина 60–4000, высота 40–4000); пустой адрес/канал в панели не принимается (раньше элемент пропадал после перезагрузки). Повторяющиеся `id` в сцене исправляются при загрузке. Список `hs-chs` фильтруется по регэкспу.
- **XSS/iframe.** Все `innerHTML` — только статичные строки и иконки; пользовательский текст идёт через `textContent`. У iframe веб-виджета убраны `allow-forms` и `allow-popups`, у Twitch — `allow-forms`/`allow-popups`; добавлены `referrerpolicy` и `title`.
- **Диалог 7TV.** Задержка ввода 500 мс, отмена устаревших запросов (`AbortController`), состояния «Ищу…», «Ничего не найдено», ошибка сети/сервиса, Enter ищет сразу, Esc и клик по фону закрывают.
- **Тост** больше не перекрывается панелью инструментов (она теперь снизу).

## Добавлено

- Единая модальная система (порт `modal` из app.html: prompt / confirm / copy + info) — фокус-ловушка, Esc, Enter, клик по фону, `aria-modal`, анимация, проверка ввода и подсказки в плейсхолдерах. Все `prompt()/confirm()/alert()` заменены: новая сцена, переименование, ссылка на картинку, браузер, стрим, добавить канал, копирование ссылки (запасной вариант), новая ссылка OBS, очистка сцены, удаление сцены, удаление стримера.
- Отмена/повтор (Ctrl/Cmd+Z, Ctrl+Shift+Z, Ctrl+Y и две кнопки) — до 50 шагов на сцену; перетаскивание и слайдеры объединяются в один шаг.
- Клавиши: стрелки (1 px, с Shift — 10 px), Ctrl+D (копия), Esc (снять выбор), `?` — окно «Горячие клавиши»; не срабатывают при вводе в поле.
- Щипок двумя пальцами и панорама на телефоне; ограничение и нормализация колеса мыши (масштаб 0.1–3).
- В панели элемента появился блок «Анимация» (движение, появление/скрытие, скорость) — поля `anim`, `fx`, `dur` уже были в формате, но не редактировались; заголовок панели с кнопкой закрытия.
- Пустые состояния: «Пусто. Добавьте элемент снизу» с пояснением, пустой список слоёв.
- Переименование сцены кнопкой-карандашом (раньше только двойной клик).

## Изменено

- Панель инструментов: SVG-иконка перед каждой кнопкой (Текст, Фото, Ссылка, 7TV, Браузер, Стрим, Таймер, Фон-стрим, Очистить, Вид); на экранах уже 700 px — только иконки с подсказками (`title`, `aria-label`). Иконки также у слоёв, кнопок панели, чипов сцен и кнопок меню.
- Слои: плавное появление/исчезновение строк, переключатели «глаз» и «замок» в строке, управление с клавиатуры (`button`).
- Мобильная раскладка 390 px: панель — «шторка» над панелью инструментов, верхняя панель без наложений.
- Состояния disabled (Выше/Ниже, отмена/повтор, Очистить, «Выключить фон-стрим»), единые радиусы 8/16 px, стили hover/focus, `prefers-reduced-motion`.
- Анимации только `transform`/`opacity`: панель, модальные окна, тосты, строки слоёв, рамка выделения, нажатие кнопок.
- CSS собран в один набор правил без визуальных изменений (графит + красный акцент).
- Обучение (#tour): тексты под нижнюю панель, новый шаг про отмену/повтор, `aria-modal`, фокус на кнопке «Далее».
- Тексты уточнены: подписи кнопок, подсказки, сообщения об ошибках; демо-подсказка показывается уведомлением.
