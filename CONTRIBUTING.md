# Участие в проекте

Спасибо, что хотите помочь! Проект — три статических HTML-файла без сборки.

## Быстрый старт

```bash
python -m http.server 8000
```

Откройте `http://localhost:8000/`. Для входа и сохранения нужен свой проект Supabase (см. README, «Настройка Supabase»). Без него работают лендинг и демо-режим `studio.html?demo=1`.

## Правила

- **Без сборки и зависимостей.** Чистые HTML, CSS и JS. Внешние скрипты только с `cdn.jsdelivr.net` и только с SRI.
- **Не ослабляйте CSP** (`script-src`, `connect-src`). Любое новое внешнее соединение обсуждайте в issue.
- **Только Twitch-вход.** Не добавляйте вход по паролю без обсуждения.
- **Стиль:** графит и красный `#df3939`, иконки только SVG со штрихом 1.75, шрифты Manrope/Inter.
- **Анимации:** только `transform` и `opacity`, длительности из CSS-переменных `--d-fast/--d-base/--d-slow`, обязательно уважайте `prefers-reduced-motion`, не допускайте сдвигов макета.
- **Тексты** на русском, короткие, понятные тем, кто видит продукт впервые.
- **Доступность:** клавиатура, `aria-*`, видимый фокус.

## Перед pull request

1. Проверьте синтаксис встроенных скриптов (`node --check` на извлечённом JS).
2. Пройдите руками: вход, добавление и удаление стримера, ссылка для OBS, мобильная ширина 390px.
3. Консоль браузера без ошибок.
4. Если меняли работу с БД, обновите `supabase/schema.reference.sql` и `SECURITY.md`.

Коммиты — короткие, в повелительном наклонении. Один PR — одно изменение.

> Лицензия проекта пока не выбрана: отправляя PR, вы соглашаетесь, что владелец решит это позже.
