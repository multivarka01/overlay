# Stream Overlay

Бесплатная студия оверлеев для стрима на Twitch. Расставляете картинки, 7TV-эмодзи, текст, таймеры, браузерные виджеты и чужие стримы на бесконечном полотне, вставляете **одну ссылку** в OBS (Browser Source 1920×1080), и всё, что вы меняете в студии, сразу появляется в эфире.

> **Лицензия пока не выбрана.** Пока владелец проекта не добавил файл `LICENSE`, код опубликован «как есть», и права на его использование и распространение не определены. Если вы хотите использовать код, откройте issue и спросите.

## Возможности

- Бесконечное полотно с подсвеченной зоной кадра 1920×1080, масштаб колесом, перемещение мышью.
- Элементы: текст, таймеры, картинки и GIF, 7TV-эмодзи (поиск по каналу и названию), источник «Браузер» (донат-виджеты, чаты, любые страницы), чужой стрим Twitch.
- Сцены и несколько стримеров в одном аккаунте (до 10), у каждого своя ссылка для OBS.
- Realtime: изменения из студии мгновенно доходят до OBS без обновления страницы.
- Вход только через Twitch, без паролей.
- Демо-режим без входа: `studio.html?demo=1`.

## Как это устроено

Проект состоит из статических HTML-файлов без сборки и бэкенда на вашей стороне. Всё хранение и realtime обеспечивает [Supabase](https://supabase.com).

| Файл | Что делает |
|---|---|
| `index.html` | Лендинг: описание, тарифы, FAQ, вход и переход в панель. |
| `app.html` | Панель: список стримеров, ссылки для OBS, подсказка по подключению к OBS, быстрый вход в студию. |
| `studio.html` | Редактор оверлея. Он же показывает оверлей в OBS, если открыть его с `?o=КЛЮЧ` (режим оверлея, без интерфейса, с прозрачным фоном). |
| `supabase/schema.reference.sql` | Восстановленная справочная схема БД (см. предупреждение ниже). |

Схема работы:

1. Пользователь входит через Twitch (Supabase Auth, PKCE) в `studio.html` или с лендинга.
2. Сцена стримера хранится строкой в таблице `scenes` (JSON в поле `data`); у строки есть секретный `overlay_key`.
3. Редактор сохраняет сцену в таблицу и рассылает изменения в приватный realtime-канал `ov:<overlay_key>`.
4. OBS открывает `studio.html?o=<overlay_key>`: страница читает сцену через функцию `get_overlay_scene(k)` и слушает канал `ov:<overlay_key>`.
5. Картинки, загруженные в студии, лежат в публичном бакете Storage `images`. Если загрузка не удалась, редактор встраивает небольшие картинки прямо в сцену.

## Настройка Supabase

> Схема в `supabase/schema.reference.sql` **восстановлена по клиентскому коду**, а не выгружена из настоящего проекта. Сравните её с вашей базой, прежде чем применять.

1. Создайте проект на supabase.com.
2. **Authentication → Providers → Twitch**: включите провайдер, вставьте Client ID и Secret из [консоли разработчика Twitch](https://dev.twitch.tv/console), в Twitch добавьте Redirect URL из Supabase.
3. **Authentication → URL Configuration**: добавьте адрес, где будут лежать страницы (например, `http://localhost:8000`), в Site URL и Redirect URLs.
4. **SQL Editor**: выполните `supabase/schema.reference.sql` (после сверки).
5. **Realtime**: убедитесь, что Realtime включён, а в настройках разрешены приватные каналы (Authorization).
6. В `index.html`, `app.html` и `studio.html` замените константы `SB_URL` и `SB_KEY` на `Project URL` и `anon public` ключ вашего проекта. Также замените хост в `connect-src` внутри `<meta http-equiv="Content-Security-Policy">`. Если используете вход через браузер из приложения для Windows, укажите свой `OAUTH_CLIENT_ID` в `studio.html`.
7. Прочитайте [SECURITY.md](SECURITY.md): RLS должен быть включён.

## Запуск локально

Нужен любой статический сервер. Открывать файлы двойным щелчком (`file://`) нельзя: не заработает вход.

```bash
python -m http.server 8000
# откройте http://localhost:8000/index.html
```

## Как добавить оверлей в OBS

1. В панели (`app.html`) нажмите **«Ссылка для OBS»** у нужного стримера. Ссылка секретная.
2. В OBS в блоке «Источники» нажмите **+ → «Браузер»** (Browser Source), вставьте ссылку в поле **URL**.
3. Ширина **1920**, высота **1080**. Больше ничего отмечать не нужно. Нажмите OK.

Если ссылки ещё нет, откройте студию для этого стримера и добавьте любой элемент: ссылка создаётся при первом сохранении сцены.

## Приложение для Windows

Необязательно: это удобное окно студии с автообновлением. Установщик берётся со страницы Releases репозитория (`Overlay-Studio-Setup.exe`). Кнопка скачивания скрыта внутри самого приложения, на мобильных устройствах и (в панели) для уже запущенного приложения.

## FAQ и решение проблем

**«Не удалось загрузить: The database schema is invalid or incompatible»**
Это ошибка Supabase Storage: схема хранилища сломана **на стороне проекта**, а не в редакторе. Что проверить:
1. Перезапустите проект (Project Settings → General → Restart project).
2. Обновите/почините Storage: в Dashboard обновите версию проекта (Infrastructure → Upgrade), при необходимости напишите в поддержку Supabase.
3. Проверьте, что бакет `images` существует и **публичный** (Storage → Buckets), лимит файла и разрешённые типы подходят, а политика `insert` на `storage.objects` разрешает запись в папку `<uid>/`.

Редактор при ошибке загрузки встраивает небольшие картинки прямо в сцену, так что работа не блокируется, но сцена становится тяжелее.

**«Достигнут лимит: максимум 10 стримеров»**
В аккаунте не больше 10 стримеров (строк в `scenes`). Удалите ненужного в панели. Если вы меняли лимит в SQL-политике, не забудьте обновить `MAX` в `app.html`.

**Панель просит войти по кругу или пишет «Не получается войти»**
Проверьте, что браузер не блокирует cookies и localStorage, адрес страницы указан в Redirect URLs Supabase, а Twitch-провайдер включён. Кнопка «Войти заново» очищает локальные данные входа.

**Панель пишет «Не удалось подключиться»**
Supabase недоступен или нет интернета. Нажмите «Повторить».

**Ссылки для OBS не загрузились (плашка вверху панели)**
Остальная панель работает; нажмите «Повторить» в плашке.

**В OBS пусто**
Проверьте размер 1920×1080, что ссылка скопирована целиком, что в студии есть элементы и что вы не пересоздавали ссылку («Новая ссылка» делает старую недействительной).

**Аватарки не грузятся**
Они берутся с `unavatar.io` (по нику Twitch). Если сервис недоступен, показывается первая буква ника.
