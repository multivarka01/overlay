# Twitch Badge Bot

Сам «смотрит» стримы, набирает время для дропов (значки, эмоуты) и забирает их. Управление и уведомления через Telegram. Работает на бесплатном Render.

По умолчанию (`MINE_MODE=badges`) майнит все кампании со значками и эмоутами, в том числе будущие. Привязывать игровые аккаунты для них не нужно.

## Установка (около 20 минут)

**1. Telegram.** В @BotFather → `/newbot` → скопируй токен. Свой числовой ID узнай у @userinfobot.

**2. Supabase** (чтобы токен Twitch не пропадал при перезапуске Render). Создай проект, выполни `schema.sql` в SQL Editor. Из Project Settings → API возьми URL и **secret / service_role** ключ (не anon).

**3. Render.** Залей папку в приватный GitHub-репозиторий. На Render: New → Blueprint → выбери репозиторий. Заполни переменные: `TELEGRAM_TOKEN`, `ALLOWED_USER_ID`, `SUPABASE_URL`, `SUPABASE_KEY`.

**4. Чтобы сервис не засыпал.** На uptimerobot.com создай HTTP-монитор на `https://ИМЯ.onrender.com/health` с интервалом 5 минут. Бот ещё сам пингует свой адрес раз в 10 минут как запасной вариант.

**5. Вход в Twitch.** Напиши боту `/login`, он пришлёт код. Введи его на twitch.tv/activate. Если вход по коду не сработает, возьми cookie `auth-token` (F12 → Application → Cookies → twitch.tv) и отправь `/token значение`. Сообщение бот удалит.

## Команды

`/status`, `/campaigns`, `/pause`, `/resume`, `/refresh`, `/mode badges|all`, `/games Название, Название`, `/login`, `/token`.

## Важно

- **Не проверено на живом Твиче.** Логика проверена тестами на имитированных данных, но у меня нет доступа к Твичу. Проверь на любой активной кампании до 18 ноября: включи `/mode all` и смотри `/campaigns` и `/status`.
- **Запросы Twitch меняются.** Бот сам подтягивает свежие хэши из репозитория TwitchDropsMiner. Если и они устарели, пришлёт сообщение.
- **Не смотри Твич с этого же аккаунта** во время майнинга: прогресс собьётся.
- **Нарушение ToS.** Автоматический просмотр запрещён правилами Twitch. Риск небольшой, но он есть.
- **Токен = доступ к аккаунту.** Храни его только в Supabase и переменных Render. Ключ Supabase должен быть secret, не anon.
