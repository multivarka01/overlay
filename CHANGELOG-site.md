# CHANGELOG-site: index.html и app.html

## Исправлено

### app.html (панель)
- **Сессия истекла / Supabase недоступен.** Раньше страница оставалась пустой или бесконечно перенаправляла на `studio.html?next=app`. Теперь: при сетевой ошибке или таймауте (12 с) показывается понятное состояние с кнопками «Повторить» и «На сайт»; без сессии выполняется переход на вход, но **защита от цикла**: после двух переходов за минуту (или если `sessionStorage` недоступен) панель показывает «Не получается войти» с кнопками «Войти заново» и «Повторить». Не загрузился скрипт Supabase — отдельное сообщение.
- **Выход из другой вкладки или потеря сессии** (`SIGNED_OUT`) ведёт на вход, а не оставляет мёртвую панель.
- **`S.rows` больше не проглатывается.** Ошибка загрузки ссылок (в том числе `r.error`, которую раньше не проверяли) показывает мягкую плашку «Не удалось загрузить ссылки для OBS» с кнопкой «Повторить»; карточки при этом не врут «ссылка ещё не создана», а пишут «Не удалось проверить ссылку».
- **Удаление при неизвестном состоянии ссылок блокируется** (иначе сцены стримера остались бы на сервере, а запись исчезла локально).
- **localStorage:** битый JSON и не-массивы в `hs-chs`/`hs-hidden` восстанавливаются (ключ очищается, данные не падают); ники приводятся к нижнему регистру, дубликаты убираются; ошибка записи (квота/отключённое хранилище) больше не молчит: список держится в памяти вкладки и показывается предупреждение.
- **Валидация ника:** принимает `@ник` и ссылку `twitch.tv/ник`, отклоняет дубликаты и зарезервированное `main`, понятные сообщения.
- **Лимит 10 стримеров:** в диалоге добавления показывается «добавлено N из 10»; при достижении лимита вместо поля ввода выводится объяснение. Учитываются и скрытый собственный канал со строкой на сервере.
- **«Ссылка для OBS» без строки:** вместо тоста, который ничего не объяснял, диалог «Ссылки пока нет» с объяснением и кнопкой «Открыть студию» для этого стримера.
- **Удаление стримера:** защита от двойного клика и повторного подтверждения; корректно при удалении выбранного, последнего, собственного канала (скрыть/вернуть через «Добавить»); при ошибке запись сохраняется и карточка возвращается; после удаления фокус не теряется; устаревшие `hs-dash-s`/`hs-wk` очищаются.
- **Ссылка для OBS** строится через `new URL('./', location.href)`: раньше при `file://` получалось `null/...`.
- **Аватарки:** цепочка источников с запоминанием неудач и буквой-заглушкой; для пользователя больше не запрашивается `unavatar.io` по отображаемому имени (оно не ник).
- **Мобильное меню:** затемнение-подложка, закрытие по клику вне, по Escape, по смене раздела и при расширении окна, кнопка «×», перенос фокуса внутрь и возврат на кнопку «Меню»; закрытая панель не попадает в Tab (`inert`).
- **Поповеры:** `z-index` и прокрутка при длинном списке, клавиши ↑ ↓ Home End ← →, Escape возвращает фокус, закрытие при уходе фокуса.
- **Дубли слушателей:** обработчики страницы и поповера навешиваются один раз через делегирование; повторы `init()` защищены; одновременное открытие двух диалогов добавления исключено.
- **Выход:** при отсутствии сети `signOut()` раньше не очищал локальную сессию. Теперь пробуется глобальный выход с таймаутом 4 с, затем локальный, затем зачистка ключей Supabase. Так же исправлен выход на лендинге.
- Рамка фокуса больше не меняет `border-radius` элементов. Тост закрывается при открытии диалога. Контраст `--t3` повышен.
- Старая ссылка `app.html?demo=1` перенаправляется на `studio.html?demo=1`.

### index.html (лендинг)
- **Кнопка «Демо»** вела на `app.html?demo=1`, где демо не существует, и показывалась только вошедшим. Теперь «Посмотреть демо» → `studio.html?demo=1`, видна всем.
- **Копирайт про вход.** Лендинг обещал «почту и пароль», а вход только через Twitch: исправлены шаг «Как это работает», макет формы и список инструментов. Кнопка «Начать бесплатно» ведёт сразу на вход (`studio.html?next=app`).
- **Состояние входа:** пока сессия неизвестна, кнопки входа скрыты без сдвига макета (раньше «Войти» мигало у вошедших); если скрипт Supabase не загрузился, кнопка входа всё равно появляется; для аватарки есть запасной вариант.
- **«Скачать для Windows»** показывалась только вошедшим. Теперь видна всем на десктопе и скрыта в приложении (Tauri) и на мобильных.
- **FAQ:** `id`, `aria-controls`, `role=region`, `aria-labelledby`, закрытые ответы недоступны для Tab и скринридеров, навигация ↑ ↓ Home End. Таблица сравнения: `caption`, `scope`, подписи «Да»/«Нет» у иконок.
- **Якоря** получили `scroll-margin-top` под фиксированной шапкой. Убран `content-visibility:auto` (давал скачки при переходе по якорю).
- Год в подвале выставляется скриптом (без JS не показывается).
- Фокус-кольцо на всех интерактивных элементах.
